# Feather Markdown 微信小程序版

这是独立于桌面应用的轻量单文件版本，不包含工作区。

## 交互

- 默认只显示 Markdown 预览。
- 点击右上角“编辑”，预览区域会原位切换为编辑器。
- 点击“完成”保存本机草稿，并立即回到预览。
- 支持从微信会话选择 `.md`、`.markdown` 或 `.txt` 文件。
- 支持复制 Markdown；支持 `wx.shareFileMessage` 时可直接导出文件，否则回退为复制内容。

## 打开项目

1. 使用微信开发者工具导入本目录。
2. `project.config.json` 默认使用 `touristappid`，正式发布前替换为自己的小程序 AppID。
3. 构建并在真机上验证文件导入、导出与系统分享。

当前内置轻量 Markdown 渲染器支持标题、段落、粗体、斜体、删除线、链接、图片、引用、列表、任务列表、代码块、分隔线和表格。Mermaid 在小程序版中以源码块显示。
